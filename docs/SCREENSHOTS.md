# Screenshots

Screenshots of every screen in the app. Drop PNGs into this directory and
they'll be picked up by the README's image tags.

## Planned layout

```
docs/screenshots/
├── 01-auth.png             # Google sign-in
├── 02-device-scan.png      # SSDP discovery list of Fire TVs
├── 03-pairing.png          # 4-digit PIN entry
├── 04-remote.png           # Main remote (dpad, media, volume)
├── 05-apps.png             # Apps grid + custom-app launcher
├── 06-touchpad.png         # Touchpad surface
├── 07-quick-actions.png    # Power, sleep, app shortcuts
├── 08-settings.png         # Settings + account + storage
└── 09-gemini.png           # Mic button + assistant reply
```

## Filename conventions

- Lowercase, hyphenated
- `NN-name.png` for ordered screenshots, padded 2 digits
- Light theme shots preferred for documentation; dark theme for marketing
